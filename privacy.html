Privacy policy — Kuber Gmail (personal)

Effective date: 2026-10-04

Kuber is a private tool used by a single person, its owner, on the owner's own computer. This policy describes how it handles Google user data.

Data accessed

With the Gmail read-only scope (https://www.googleapis.com/auth/gmail.readonly), Kuber reads the owner's own Gmail messages. It cannot send, change, label or delete email.

How the data is used

Messages are read and processed locally on the owner's computer, only to update the owner's personal finance records (for example, reading the available balance from the owner's bank alert emails).

  • No data is collected by, or sent to, any server operated for Kuber.
  • No data is stored off the owner's device, sold, or shared with third parties.
  • No data is used for advertising.
  • No one other than the owner reads the data.

Storage and retention

The OAuth token is kept only on the owner's computer, in a folder readable by the owner alone. Extracted figures stay in the owner's local records. Access can be revoked at any time at myaccount.google.com/permissions; deleting the local token file also ends access.

Google API Services User Data Policy

Kuber's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

Changes to this policy are published on this page with a new effective date. Questions: open an issue on GitHub.
